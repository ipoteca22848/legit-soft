# bamber client 1.0.0

Готовый JAR: [Releases](https://github.com/ipoteca22848/legit-soft/releases). Автоматическая сборка: [Actions](https://github.com/ipoteca22848/legit-soft/actions).

Мод для Minecraft Java Edition **1.21.11**, Fabric Loader **0.19.5** (минимум 0.19.3), Java **21** и Fabric API **0.141.6+1.21.11**.

## Установка

1. Установите профиль Fabric для Minecraft 1.21.11.
2. Скопируйте `bamber-client-1.0.0.jar` и Fabric API для 1.21.11 в папку `mods` этого профиля. В архиве `bamber-client-1.21.11-mods.zip` оба файла уже находятся в папке `mods`.
3. Уберите отдельно установленный присланный `item-model-fix`: его движок уже встроен в bamber client. Одновременная установка запустит отдельный экземпляр со старыми фиксированными клавишами.
4. Запустите игру через профиль Fabric.

## Управление

- **Правый Shift** — открыть Click GUI.
- ЛКМ по модулю — включить/выключить; ПКМ — открыть настройки.
- Средняя кнопка мыши по модулю, затем клавиша — назначить бинд; Delete — убрать бинд.
- **TriggerBot** находится в **Combat**. Изначальный бинд — **R**. Его также можно менять через настройку «Бинд активации». Изменения сохраняются в конфигурации.
- **Unhook** находится в **Util**. Он выключает модули, триггербот, визуальные эффекты и сетевые подключения клиента до перезапуска игры. Конфигурация сохраняется перед отключением. Это отключение функций в текущем процессе; Fabric и уже применённые mixin-преобразования классов из JVM не выгружаются.
- Специальные редакторы, конфиги, темы, косметика, маркеры и другие исходные разделы доступны через **Settings → Все настройки → Открыть настройки**. Сложные настройки модулей открывают исходный редактор сразу с выбранным модулем.

Все 94 модуля исходного визуального клиента подключены к Click GUI. Из Rich перенесены интерфейс и необходимые библиотеки отрисовки; его игровые модули не включены. Главное меню взято из отдельно присланного mainmenu.zip. Алгоритм триггербота сохранён в отдельном встроенном движке; заменены обработка фиксированных клавиш и регистрация обработчиков, добавлен сброс отложенной атаки при выключении.

Сетевые функции исходных визуалов по-прежнему зависят от доступности их исходных серверов. Проверки выполнялись без доступа к внешней сети; работа этих серверов и многопользовательская игра не проверялись.

## Сборка исходников

Нужен JDK 21. Linux/macOS: `bash gradlew build`. Windows: `gradlew.bat build`.

Готовый мод: `build/libs/bamber-client-1.0.0.jar`.

Локальная интеграционная проверка: `bash gradlew runClient -Psmoke`. Она открывает главное меню и Click GUI, проверяет покрытие модулей, загрузку движка триггербота, сохранение бинда и отключение через Unhook. Тестовый код не включается в обычную сборку. Запускайте этот режим без внешней сети, если не нужно подключение исходных сетевых сервисов.
