# anvil visual 1.3.0

Готовый JAR: [Releases](https://github.com/ipoteca22848/legit-soft/releases). Автоматическая сборка: [Actions](https://github.com/ipoteca22848/legit-soft/actions).

Мод для Minecraft Java Edition **1.21.11**, Fabric Loader **0.19.5** (минимум 0.19.3), Java **21** и Fabric API **0.141.6+1.21.11**.

## Установка

1. Установите профиль Fabric для Minecraft 1.21.11.
2. Скопируйте `anvil-visual-1.3.0.jar` и Fabric API для 1.21.11 в папку `mods` этого профиля. В архиве `anvil-visual-1.21.11-mods.zip` оба файла уже находятся в папке `mods`.
3. Удалите старый bamber JAR перед установкой. Триггербот и его встроенный движок удалены; отдельно установленный item-model-fix не относится к этому моду.
4. Запустите игру через профиль Fabric.

## Управление

- **Правый Shift** — открыть Click GUI.
- ЛКМ по модулю — включить/выключить; ПКМ — открыть настройки.
- Средняя кнопка мыши по модулю, затем клавиша — назначить бинд; Delete — убрать бинд.
- **Unhook** находится в **Util**. Он выключает модули, визуальные эффекты и сетевые подключения клиента до перезапуска игры. Конфигурация сохраняется перед отключением. Это отключение функций в текущем процессе; Fabric и уже применённые mixin-преобразования классов из JVM не выгружаются.
- **Конфиги**, **Метки**, **Косметика**, **Темы**, **HUD**, **Ивенты**, **Шахты**, **Мессенджер** и **Настройки** — отдельные нативные вкладки нового Click GUI. Прокручивайте левую панель колёсиком для доступа ко всем вкладкам.
- Во вкладке **Косметика** сразу отображается сетка с 3D-превью и названиями. Сверху — категории, колёсико прокручивает каталог, ЛКМ по карточке надевает/снимает предмет.
- Открытия старого Click GUI больше нет. Сложные настройки предметов, цветов и друзей редактируются непосредственно в новом интерфейсе.
- Во вкладке **HUD → Инвентарь** можно полностью выключить HUD инвентаря. Переключатель сохраняется в конфиге. Там же доступны настройки каждого элемента: положение, масштаб, цвета, материал, тень, блюр, свечение и обводка.
- **Спокойные эффекты HUD** включены по умолчанию: фон захватывается один раз за кадр из чистого кадра мира, движущиеся блики и искажения HUD заморожены. Субъективный комфорт на пользовательской видеокарте и совместимость со всеми сторонними модами требуют проверки в игре.

Все 94 модуля исходного визуального клиента подключены к Click GUI. Из Rich перенесены интерфейс и необходимые библиотеки отрисовки; его игровые модули не включены. Главное меню взято из отдельно присланного mainmenu.zip. Триггербот удалён. Добавлен настраиваемый Discord Rich Presence.

Сетевые функции исходных визуалов по-прежнему зависят от доступности их исходных серверов. Проверки выполнялись без доступа к внешней сети; работа этих серверов и многопользовательская игра не проверялись.

## Сборка исходников

Нужен JDK 21. Linux/macOS: `bash gradlew build`. Windows: `gradlew.bat build`.

Готовый мод: `build/libs/anvil-visual-1.3.0.jar`.

Локальная интеграционная проверка: `bash gradlew runClient -Psmoke`. Она открывает главное меню и Click GUI, проверяет покрытие модулей, отсутствие триггербота, Discord RPC и отключение через Unhook. Тестовый код не включается в обычную сборку. Запускайте этот режим без внешней сети, если не нужно подключение исходных сетевых сервисов.

## Проверка устанавливаемого JAR

`bash gradlew build remapProductionSmoke` собирает релиз и отдельный тестовый мод `build/libs/anvil-visual-1.3.0-smoke.jar`. Для проверки обычной установки поместите оба JAR и Fabric API в тестовый профиль Minecraft 1.21.11 с Fabric. Тест проверяет также инициализацию стекла, эффектов рук и слоёв окраски при ударе. Тестовый JAR не нужен в обычной игре. Выполняйте проверку без внешней сети.

Для ивентов FunTime укажите свой ключ во вкладке «Ивенты → Сервер и обновление → Свой ключ API FunTime» и нажмите «Применить ключ». Встроенных ключей сервиса в этой версии нет. Ключ применяется до перезапуска игры.

В 1.3.0 хотбар закреплён у нижнего края окна без тени поверх здоровья и голода, на ватермарке буква «A». В модуле Optimization доступны кнопки «Minecraft: Баланс FPS», «Minecraft: Максимум FPS» и восстановление настроек. Выключение Optimization также восстанавливает настройки, сохранённые перед применением профиля в текущем запуске. Прирост FPS не измерен и зависит от оборудования.

Discord RPC включён по умолчанию с Application ID `1568234202254807080`. Откройте настольный Discord и разрешите показ игровой активности. Название активности Discord берёт из приложения с этим ID. Во вкладке Misc модуль DiscordRPC позволяет отключить статус или заменить Application ID. Выбранный ID сохраняется в `config/anvil_visual_discord.json`; Unhook закрывает соединение. Токен не нужен.

Модели мечей: вкладка «Мечи» или кнопка «Каталог моделей с превью» в Custom Sword. Выберите материал, затем карточку модели: она применяется сразу и сохраняется в конфигурации. Верхняя кнопка выключает замену для выбранного материала. Превью используют настоящий игровой рендерер и данные модели.

Вкладка «Мечи» находится сразу под «Визуалы» и видна без прокрутки. Версия установленного мода отображается внизу левой панели и в главном меню.

В 1.3.0 вкладки Combat и Movement удалены; список начинается с «Визуалы» и «Мечи». Тени HUD рисуются через очередь GUI с кэшированными масками размытия.

В 1.3.0 добавлены «Атмосфера» (Визуалы) и стиль ватермарка «Островок» (HUD → Все элементы HUD → Ватермарк). Стиль островка включён по умолчанию; прежний вид доступен как «Обычный». Атмосфера содержит исходный снегопад с плотностью, радиусом, скоростью и ветром, зимние текстуры и зимний туман. Зимний ресурс-пак включается и выключается автоматически вместе с соответствующей настройкой; переключение требует перезагрузки ресурсов. Алгоритм снегопада, тумана и зимние ресурсы адаптированы из предоставленного myth.rar; текстуры Snowstorm сохраняют указание автора Ewan Howell. Рисунок снежинки перенесён из исходного шейдера в текстуру для существующего рендерера. Островок воспроизведён по предоставленному изображению, поскольку в архиве другой ватермарк. Счётчик FPS не изменён по просьбе пользователя.

В 1.3.0 модуль Optimization дополнен оптимизацией из Pulse: графика с условным восстановлением, FPS в фоне, куллинг сущностей и блок-энтити, бюджет частиц, лимиты предметов, дистанции рамок/табличек, листва, кэш неба, свет, тосты, текст/атлас и сглаживание чанков. Включение «Настройки Minecraft» применяет профиль Pulse, включая FPS cap 260 и выключение VSync; отключение возвращает только параметры, которые пользователь не менял вручную. Атлас увеличивается после перезагрузки ресурсов. EntityCulling, ImmediatelyFast, CullLeaves, MoreCulling, Dynamic FPS и BadOptimizations учитываются для соответствующих функций. Счётчик FPS не подменяется этим модулем; числовой прирост не обещается.

Косметика: все прежние 78 предметов сохранены с теми же ID и ресурсами. Встроены все 63 предмета из Cosmetics_bundle.zip и базовый плащ из Pulse.zip: всего 142. Добавлены категории «Плащи» и фильтр «Pulse». Плащ можно носить вместе с предметом на спине; новая косметика выбирается и сохраняется как старая. Никаких загрузок с сервера Pulse и локального кэша не требуется. Анимированные текстуры выбирают кадр через UV-координаты: без копирования пикселей и загрузки текстуры на GPU каждый тик.
