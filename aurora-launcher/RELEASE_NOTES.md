Aurora Launcher — Windows x64 preview.

Скачайте установщик .exe или Aurora-Launcher-Portable.exe. Требуется Microsoft Edge WebView2 (установщик предложит установить).

Реализованы отдельные профили, Vanilla/Fabric/Quilt/Forge, offline UUID, Microsoft device flow (нужен собственный Client ID с доступом Minecraft API), Java 8/17/21, многопоточная установка, Modrinth и CurseForge (нужен API-ключ), зависимости модов и прогресс.

Предварительная версия: Microsoft-вход и запуск Minecraft требуют проверки на реальном аккаунте/Windows; гарантии 10–20 МБ нет. Движок поддерживает версии Minecraft начиная с 1.16.5; snapshots не предлагаются. Не является официальным продуктом Mojang/Microsoft.
